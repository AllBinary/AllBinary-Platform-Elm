                             AllBinary Platform Elm

What is it?

This repository contains code generated by the AllBinary Platform for support in Elm.  
This repo is used to allow developers to skip the Elm code generation step.

What are some example games with this Elm code?

https://allbinary.itch.io (The downloads with "-elm" in the filename are Elm only builds. Currently that only includes nothing. Also the Elm builds are not available on Google Play or other stores.)
